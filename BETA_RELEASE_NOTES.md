# Fintra 9.6.0-beta.44

Schwerpunkt dieser Testversion ist ein vollständiges visuelles Redesign der bestehenden Oberfläche.

- komplettes CSS neu aufgebaut
- moderneres Fintech-Dashboard mit weicheren Flächen und klarerer Informationshierarchie
- überarbeitete Navigation, Karten, Tabellen, Formulare, Buttons und Dialoge
- konsistenter Light- und Dark-Mode
- responsive Darstellung für Desktop, Tablet und Smartphone überarbeitet
- keine bewussten Änderungen an Datenmodell oder Geschäftslogik

Diese Beta ist ausdrücklich zum visuellen Vergleich mit beta.43 gedacht.

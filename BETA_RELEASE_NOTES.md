# Fintra 9.6.0-beta.45

## UI refinement

- Page titles use a smaller, lighter and more neutral type treatment.
- The annual overview table has wider desktop columns so monetary values stay readable.
- The burger-menu icon is vertically and horizontally centered.
- Category headings have more spacing before the lists.
- The Fintra mark on the login page is transparent again.

No application logic was changed in this release.

# Fintra 9.6.0-beta.46

Diese Testversion verfeinert das moderne UI aus Beta 45.

## Änderungen

- Die Desktop-Oberfläche nutzt deutlich mehr der verfügbaren Fensterbreite.
- Die Jahresübersicht auf der Hauptseite passt ihre Spalten an die verfügbare Breite an und benötigt auf Desktop keinen horizontalen Scrollbalken mehr.
- Die Fixkostentabelle wurde kompakter aufgebaut, damit Monatswerte, Jahressumme und Aktionen gleichzeitig sichtbar bleiben.
- Auf kleineren Bildschirmbreiten wird automatisch die bereits vorhandene mobile Kartenansicht verwendet, statt eine breite Tabelle scrollbar zu machen.
- Bei Fixkosten wird die Bezeichnung im normalen Zustand nur einmal angezeigt. Das Eingabefeld erscheint erst nach Klick auf „Bearbeiten“.

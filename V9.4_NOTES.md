# Fintra V9.4

Grundbasis: vom Benutzer hochgeladene `fintra-v9.3.tar.gz`.

## Navigation
Die bisher volle Navigationsleiste wurde aufgeräumt.

Direkt sichtbar:
- Fintra
- Übersicht
- Neue Transaktion
- Light/Dark-Mode
- Burger-Menü

Im Burger-Menü:
- Fixkosten
- Kategorien
- Budgets
- Finanzanalyse
- Algorithmen & Datenstrukturen
- CSV-Export
- Datenbank-Backup
- Benutzername
- Abmelden

## Bedienung
- Menü öffnet/schließt per Klick.
- Burger-Icon animiert zu einem X.
- Klick außerhalb schließt das Menü.
- Escape schließt das Menü.
- Auf kleineren Displays wird die Navigation weiter reduziert.
- Alle bestehenden V9.3-Funktionen bleiben erhalten.
